# Alien Database - Acceso Clasificado

**Despliegue en Producción:** [https://alienweb-red.vercel.app/](https://alienweb-red.vercel.app/)

## Resumen del Proyecto
Alien Database es una aplicación web interactiva diseñada bajo una estética *Dark Tech* / *Sci-Fi* que simula ser un sistema de archivos clasificados de acceso restringido. El proyecto está enfocado en demostrar habilidades de desarrollo frontend utilizando tecnologías "Vanilla" (HTML, CSS y JS puro).

## Características Principales
*   **Autenticación Híbrida:** Sistema de inicio de sesión validado mediante Supabase, con un mecanismo de contingencia local (fallback) en caso de fallos de red.
*   **Catálogo Dinámico:** Visualización responsiva de especies alienígenas utilizando CSS Grid.
*   **Generador de Expedientes PDF:** Creación dinámica de documentos PDF clasificados utilizando `jsPDF`, con formato editorial y estructurado.

## Tecnologías
*   HTML5 & CSS3
*   Vanilla JavaScript
*   Supabase (BaaS)
*   Vercel (Despliegue)
